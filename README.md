At last, a somewhat functional Discord rich presence plugin for Adobe Substance 3D Painter!

Full Discord rich presence integration for Bake, Paint, and IRay preview modes!

## Installation
1) Download the entire `main` branch, and extract its contents to `Documents\Adobe\Substance 3D Painter\python`.
2) Launch Substance 3D Painter, and from the top bar and check `Python > SubstanceRPC`.
3) All Set!

## Compatibility
This plugin has only been tested on Substance Painter 2025 (v11.X), up to 2026 (12.X)! I cannot guarantee functionality on any older versions!

## Support
This plugin is provided as-is, and installation support will not be provided. PRs and Issues are always welcome, however.
